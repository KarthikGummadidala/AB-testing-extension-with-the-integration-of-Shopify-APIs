A/B Testing – Visually + Shopify

Connect your Shopify store and manage experiments.

Shopify store

Use your store’s myshopify.com domain (e.g. mystore or mystore.myshopify.com). For Storefront API, use the Headless channel to get a Storefront API token.

Use a Dev Dashboard app to get an Admin API token if you need Admin API access. The extension primarily uses Storefront API.

Experiments

Experiments are stored in this browser and align with Visually concepts: variants, goals, and allocation. Use the popup to create and run live tests.
